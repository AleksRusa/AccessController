# AccessController
Code for Atmega8 - access controller, разработанно в VMLAB. В симуляторе построена система с двумя диодами, а также двумя устройствами (Atmega8 - slave и терминала - master), связанными через I2C. С терминала подаётся 8-ми битное число в 16-ой системе, если код есть в базе, то мигает один диод, если нет, другой. При подача мастер кода, контроллер ожидает подачи нового кода и записывает его в EEPROM.
