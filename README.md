# AccessController
Code for Atmega8 - access controller. В симуляторе построена система с двумя диодами, а также двумя устройствами (Atmega8 и терминала), связанными через I2C. Если код есть в базе, то мигает один диод, если нет, другой. При подача мастер кода, контроллер ожидает подачи нового кода и записывает его в EEPROM.
